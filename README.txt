# AMD - Anmol Mother's Dish Website

## Files

- `index.html` → website structure
- `style.css` → complete design and responsive layout
- `script.js` → search, product filter, cart counter, mobile menu, product modal and enquiry form
- `images/` → logo and uploaded product images

## Run

1. Extract the ZIP.
2. Open the folder in VS Code.
3. Open `index.html` in your browser.
4. For the easiest development workflow, use the VS Code Live Server extension.

## Important

The contact form is front-end only. It does not send email to a real server yet.
The cart counter is also a front-end demonstration.
